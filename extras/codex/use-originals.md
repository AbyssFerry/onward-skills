# 切回原版（仅 Codex）

让 Codex 按本文执行：只撤回记录中实际切换过的对应组，恢复原版开关。本文是可选操作文档，不是自动发现的技能，也不随 `npx skills add` 安装。

先读取 [use-onward.md 的共用约定与对应范围](use-onward.md#共用约定)，只应用这些共用内容，不执行其中的“切换到 Onward”操作。

读取同一 Codex 配置目录中的 `onward-switch.json`，核对配置路径、技能身份与安装位置。缺少记录时不能声称恢复了原有设置，应说明缺少恢复依据，先保留现有配置。

记录已是 `originals` 模式时，无需再次恢复，避免覆盖用户切回后自行调整的开关。

在明确名单内，恢复记录中原版各路径原有的 `skills.config` 条目；原先没有条目的，仅撤掉此次为它新增的覆盖项。原先关闭的原版仍保持关闭，其他技能和后来修改的无关配置保持原样。安装位置变化时先核实对应的新路径；缺失项报告并跳过，不安装、不整份覆盖配置文件。

只将这些已切换组对应的 Onward 副本设为 `enabled = false`，记录模式为 `originals`。未切换组和名单外的技能保持原样；验证与重启提示遵循共用约定。

再次使用 Onward 时执行 [use-onward.md](use-onward.md)。
