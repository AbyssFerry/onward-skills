# Agent Skill Collections

Consult this map when the user wants to discover existing Agent Skill projects or skill collections. It summarizes the upstream READMEs reviewed on 2026-11-13. Entries are leads, not rankings or endorsements; no star or skill totals are included, and the summaries do not claim that a project was installed or tested.

The labels describe different kinds of resources. A **skill collection** contains reusable skill folders; a **suite** may combine skills with agents, commands, hooks, MCP connections, or a prescribed workflow; an **index** primarily points to other resources; a **hybrid** contains both a catalog and usable components. Choose projects that fit the task, target agent, and user's priorities. Check the relevant skill, platform support, and license when considering use or adaptation; do not inspect or install every entry by default.
