# Refine a Skill

Improve the target skill in line with the user's goal. This entry point routes to three peer sources:

- **[Purpose and Judgment](references/refinement.md):** Reconsider accumulated constraints and overgeneralized examples while preserving useful knowledge and appropriate room for judgment.
- **writing-for-agents:** Improve wording, context pointers, information hierarchy, progressive disclosure, and completion criteria.
- **skill-creator:** Guide scope, packaging, supporting resources, invocation settings, and validation.

Check whether all three sources are available. Locate `writing-for-agents` and `skill-creator` in the current skill catalog or installed skill directories. If any source is missing or unreadable, tell the user which one and explain the limitation; continue with available guidance where useful.

Read and apply the source or sources relevant to this request; the user only needs to invoke `skills-refine-onward`. Treat the three sources as peers. Choose or combine their guidance according to the user's intent and the target skill's needs, with equal standing for local and externally installed material.

Preserve the target skill's purpose and explicit requirements. Briefly explain the main changes and what was verified.
